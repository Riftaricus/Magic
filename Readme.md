# Magic Skills

Magic skills is a project where I needed to obtain data from a magic the gathering API and turn it into a CSV file

## Used API:

https://scryfall.com/

## Used Language

Python

## Libraries

Pandas
Dotenv
os
subprocess
requests
colorama
Pathlib

## Requirements

All it needs is python. A non-required dependency is Git, which lets you auto-pull it from this repository it on every run.

## Install & Run

To use & install the code, run the installer.py using:
'python3 installer.py run' or 'py installer.py run'
depending on your installation

It will automatically install and run the code

If you want to install without running, do 'python3 installer.py' or 'py installer.py'

## Output

The output appears in
output/data.csv &
output/data.json

The Terminal prints out what it's currently working on and when something breaks

## Sorting

The sets are sorted by release date
